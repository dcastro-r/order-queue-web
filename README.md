# order-queue-web
Prototipo web para seguimiento de colas de pedidos en tiempo real y estado de espera de los clientes.

## Descripción

Order Queue Web es un prototipo web diseñado para mejorar la experiencia de los clientes en restaurantes de comida rápida mediante el seguimiento en tiempo real del estado de sus pedidos.

Los usuarios pueden acceder a la plataforma acercándose al restaurante y visualizar ya sea un QR o link para visualizar el estado actual de su pedido, conocer el tiempo estimado de espera y recibir información sobre cuándo estará listo para ser recogido.

---

## Objetivo

Reducir la incertidumbre durante la espera y mejorar la experiencia del cliente proporcionando información sobre el estado de preparación de los pedidos.

---

## Características

- Seguimiento de pedidos en tiempo real.
- Visualización del estado de preparación.
- Indicador de tiempo estimado de espera.
- Gestión visual de turnos y cola de pedidos.
- Interfaz moderna y responsiva.
- Acceso mediante código QR o enlace web.
